# 요룡이의 과학 모험

인천 부광고등학교의 교문에서 시작하는 픽셀아트 횡스크롤 액션 게임입니다. 요룡이가 여덟 학자의 시련을 통과하고, 과학실에 흩어진 네 인장을 되찾아 옥상의 균열을 닫습니다.

[브라우저에서 플레이](https://gungmean.github.io/yoryong/)

## 처음 플레이할 때

1. 교문에서 오른쪽으로 걸어 중앙 현관 표식에서 ↑를 누릅니다.
2. 본관 중앙 계단에서 층을 고릅니다. 2층은 물리, 3층은 화학, 4층은 생명, 5층은 지구과학입니다.
3. 같은 층의 학자 두 명에게 스킬을 배우면 해당 과목의 열쇠를 얻습니다. 1층 물리지학실에서는 물리·지구 보스, 생명화학실에서는 화학·생명 보스와 싸울 수 있습니다.
4. 네 인장을 모으면 중앙 계단에서 옥상으로 올라갈 수 있습니다. 체력과 마력은 1층 매점에서 회복할 수 있습니다.

| 조작 | 키 |
| --- | --- |
| 좌우 이동 | ← → |
| 점프 · 공중에서 한 번 더 점프 | Alt |
| 발판에서 내려오기 | ↓ + Alt |
| 기본 공격 · 회피 대시 | A · Shift |
| 장착한 스킬 사용 | Q W E R |
| 대화 · 출입 · 계단 | ↑ |
| 문제 선택 · 층 선택 | 숫자 |
| 스킬 배치 · 지도 · 메뉴 | K · M · Esc |

왼쪽 위 지역명을 누르면 캠퍼스 지도가 열립니다. 옆의 − 또는 + 버튼으로 미니맵을 접고 펼 수 있습니다. 오른쪽 위 목표를 누르면 모험 일지에서 다음 행동과 인장 수집 조건을 확인할 수 있습니다. 체력과 마력은 왼쪽 아래, 공격과 장착 스킬은 오른쪽 아래에 표시됩니다.

진행 상황은 플레이한 브라우저에 자동 저장됩니다. 오른쪽 위 메뉴에서 전체화면과 효과음을 켤 수 있습니다. 내려받은 폴더의 `index.html`을 열어 오프라인으로도 플레이할 수 있습니다.

스킬 배치에서는 Q·W·E·R 중 바꿀 슬롯을 누른 뒤 배운 스킬을 선택하세요. 터치 화면에서는 필드 아래의 방향키와 점프를 동시에 누를 수 있습니다. 메뉴에서 배경 움직임을 켜거나 끌 수 있으며, 기기의 동작 줄이기 설정도 반영됩니다.

## 에셋과 수정

요룡이는 제공된 캐릭터 원화를, 교문 배경은 학교 공식 본관 전경을 참고해 제작했습니다. 학자 초상화는 여덟 인물의 그림과 사진을 바탕으로 픽셀아트로 재구성했습니다. 층별 배치는 횡스크롤 동선에 맞췄습니다. [부광고등학교](https://bg.icehs.kr/main.do) · [본관 전경 자료](https://bg.icehs.kr/upload/sysImg/2022bg/1658385092859.jpg)

- `data.js`에서 과학 문제, 정답, 스킬, 교실 배치를 수정할 수 있습니다.
- `icons.js`는 픽셀 아이콘과 인장 메달을, `scenery.js`는 교정의 깃발, 복도 시계, 과목별 실험 장치와 옥상 배경 효과를 그립니다.
- `assets/actors/`에는 게임에 사용하는 투명 PNG 모션 시트 15장이 있습니다. 각 시트는 한 줄에 4프레임이며 왼쪽에서 오른쪽 순서입니다.
- `actor-sheets.js`에는 셀 크기, 발 위치, 기본 키, 프레임 수가 들어 있습니다. 재생 시점과 방향은 `render.js`, 공격 판정과 이동은 `game.js`가 처리합니다.
- 한글 픽셀 글꼴은 Galmuri11입니다. [폰트 라이선스](assets/Galmuri-LICENSE.txt)

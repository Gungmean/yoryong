# 필드와 UI의 픽셀 크기

게임 좌표에서 교실 배경은 1080×360, 요룡이의 키는 60이다. 같은 화면에서 인물의 키와 도트의 굵기를 따로 비교하기 위해 원본 스프라이트의 기준 키, 필드에서 그리는 키, 실제 화면에 찍히는 도트의 크기를 각각 측정했다.

| 대상 | 기존 원본 → 필드 기준 키 | 수정 후 |
| --- | --- | --- |
| 요룡이 | 110 → 60 | 28프레임을 60 기준으로 제작 |
| 학자 8명 | 99 → 교실 56, 소환 74 | 교실용은 56, 소환 32프레임은 74 기준으로 별도 제작 |
| 복도 몬스터 | 88 → 27 | 12프레임을 27 기준으로 제작 |
| 물리·화학·생명·지구·옥상 보스 | 모두 132 → 각각 153·163·180·158·219 | 각 보스의 전투 크기로 시트를 제작하고 발 위치를 함께 변환 |
| 과학실·교실·실험 기구 | 과학실 배경 1024×360, 교실 배경 1080×360, 저울 58×37, 책장 116×96 | 배경과 전경에 같은 출력 격자를 적용하고 기구의 중심과 바닥을 격자에 맞춤 |
| 스킬·보스 효과 | 기본 효과 셀 208×176, 입자·승리 효과는 클립마다 다른 크기 | 발사·착탄·소환의 기준점과 프레임 외곽을 출력 격자에 맞춤. 성장·돌진 연출은 동작에 따라 크기가 변함 |
| 스킬 아이콘·학자 초상화 | 아이콘 80×80을 24~34 CSS px로 표시. 학자 초상화는 원본 70×76 | 퀵슬롯과 배치창에 24×24 전용 아이콘 사용. 대화와 퀴즈는 70×76 초상화 사용 |

## 화면에서 측정한 결과

아래는 Chromium에서 캔버스의 실제 표시 높이와 기기 픽셀 비율을 이용해 측정한 **출력 도트 한 변의 기기 픽셀 수**다. 화면 크기와 조작 바 높이에 따라 배율을 고른다. 필드 좌표는 높이 360을 유지한다.

| 화면 크기 (CSS px) | 기기 픽셀 비율 | 수정 전 | 수정 후 |
| --- | ---: | ---: | ---: |
| 1366×768 | 1 | 1.95 | 2×2 |
| 390×844 | 3 | 5.80 | 6×6 |
| 844×390 | 2 | 1.80 | 2×2 |
| 1024×768 | 1.25 | 2.44 | 2×2 |

1366×768 교문 스크린샷에서 같은 좌표의 배경 영역(436×220 기기 픽셀)을 2×2칸으로 나눠 내부 네 픽셀의 RGB가 모두 같은지 확인했다. 일치한 칸은 30.56%에서 100%로 늘었다. 교실에서도 27.01%에서 100%가 됐다. 한글 지명과 대사는 읽기 쉽도록 별도의 고해상도 레이어에 그린다.

## 원화에서 다시 만들기

`art/actor-masters/`의 원본 모션 시트와 기준점을 사용한다. 프로젝트 루트에서 Pillow와 NumPy가 설치된 Python으로 `python art/bake_field_actors.py`를 실행하면 캐릭터·소환 시트, 프레임 정보, 소형 스킬 아이콘이 생성된다. 축소 시 면적을 기준으로 색을 뽑고 원본 팔레트와 투명 경계를 복원한다. 확대 시 같은 색이 이어지는 대각선을 먼저 보완한다.
